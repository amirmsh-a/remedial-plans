# الخطط العلاجية للاختبار التكويني 1448

موقع لمتابعة الخطط العلاجية للاختبار التكويني في **مدرسة ابن خلدون الابتدائية – عرقة**، مبني على بنية مجلد
"الخطط العلاجية للاختبار التكويني 1448": 4 مواد (الرياضيات، العلوم، اللغة العربية، اللغة الإنجليزية) بـ 32 فصلاً لكل مادة، ولكل فصل 8 مكونات:
نتائج الطلاب، تصنيف الطلاب، الخطة العلاجية، شواهد الخطة، سجل المتابعة، إشعارات أولياء الأمور، توزيع المنهج، قياس أثر الخطة.

## المزايا
- دخول بالرقم الوظيفي فقط، والأرقام يضيفها المدير من صفحة "المستخدمون".
- أدوار (مدير، مشرف، معلم، مشاهد) وصلاحيات تفصيلية لكل مستخدم، ونطاق وصول بالمواد والصفوف والفصول يُطبَّق في قاعدة البيانات.
- إضافة وتعديل وتعبئة الخطط (للجميع)، والحذف وإدارة المستخدمين (للمدير فقط).
- فلاتر: المادة، الصف، الفصل، الحالة، مستوى الإنجاز، وبحث نصي، مع ترتيب الأعمدة وتصدير CSV.
- صفحة المجلدات: تصفح المادة ← الصف ← الفصل ← مجلداته الثمانية مع روابط OneDrive وتحديد اكتمال كل مجلد.
- روابط المجلدات: يضيف المستخدمون المخوَّلون روابط ملفات ومرفقات داخل كل مجلد، ورابط مشاركة للمجلد يفتحه الجميع.
- الطلاب الضعاف: قوائم كل مادة وفصل ومعلم (رقم الهوية، الدرجة، النسبة)، ويكمل المعلم المهارات والشواهد ودرجة الاختبار البعدي وتُحسب نسبة التحسن تلقائياً، مع تقرير PDF للمدير (يتطلب `supabase-weak.sql`).
- التقارير (PDF): تقرير مادة، تقرير فصل لكل المواد، تقرير معلم، وتقرير الخطة العلاجية التفصيلي لفصل مع روابط الشواهد وخانات التوقيع.
- لوحة إحصاء: مؤشرات عامة، رسوم لإنجاز المكونات ونسب التعثر والأداء قبل/بعد الخطة لكل فصل، ملخص حسب المادة والصف، ومصفوفة مكونات كل فصل.

## الإعداد (مرة واحدة)

### 1) قاعدة البيانات — Supabase
1. أنشئ حساباً مجانياً في https://supabase.com ثم **New project** (اختر أقرب منطقة).
2. افتح **SQL Editor → New query**، والصق محتوى `supabase-setup.sql`.
3. في آخر الملف استبدل `0000000` برقمك الوظيفي، ثم اضغط **Run**.
4. شغّل بعده ملف `supabase-permissions.sql` لتفعيل الأدوار والصلاحيات.
5. ثم ملف `supabase-links.sql` لتفعيل روابط المجلدات، ثم `supabase-classes.sql` لتحديد الفصول في الصلاحيات.
6. من **Project Settings → API** انسخ **Project URL** و **anon public key**.

### 2) ربط الموقع
افتح `config.js` وضع القيمتين:
```js
SUPABASE_URL: "https://xxxx.supabase.co",
SUPABASE_ANON_KEY: "eyJ...",
```
(مفتاح anon مخصص للنشر العلني، والجداول محمية ولا تُقرأ إلا عبر دوال تتحقق من الرقم الوظيفي.)

### 3) النشر — GitHub Pages
**Settings → Pages → Build and deployment → Source: Deploy from a branch → main / (root) → Save**.
بعد دقيقة يصبح الموقع على: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## ملاحظات
- بدون إعداد Supabase يعمل الموقع في **وضع تجريبي** ببيانات نموذجية محفوظة في المتصفح (رقم الدخول: `1000`).
- الدخول بالرقم الوظيفي وحده أقل أماناً من كلمة مرور؛ لا تُدخل بيانات شخصية حساسة للطلاب.
